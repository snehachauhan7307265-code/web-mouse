================================================================
           WEBMOUSE V1 — WINDOWS HELPER
================================================================

KAISE CHALAYE (HOW TO RUN):

1. Is folder me 'run_webmouse.bat' file par DOUBLE CLICK karein.
2. Ek black Command Prompt (CMD) window khulegi.
3. Usme aapka Laptop IP aur 6-Digit PIN dikhega.
4. Mobile me WebMouse open karke PIN enter karein aur connect ho jayega!

NOTE:
- Is Command Prompt window ko band MAT karein (keep it open).
- Agar computer me Python nahi hai to www.python.org se Python install karein,
  aur install karte waqt 'Add Python to PATH' par tick mark lagayein.
